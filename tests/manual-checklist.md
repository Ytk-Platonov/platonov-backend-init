# Чек-лист ручного тестирования интеграции Frontend ↔ Backend

**Как использовать:**
1. Запусти backend: `cd server && npm start`
2. Открой фронтенд в браузере (обычно `index.html` или `http://localhost:3000`)
3. Открой DevTools → Network (F12)
4. Пройди по пунктам, отмечай ✅ или ❌
5. Для каждого ❌ — создай баг-репорт автору эндпоинта

---

## 🔐 Аутентификация

### Регистрация
- [ ] Форма регистрации отправляет `POST /api/auth/register`
- [ ] При успехе — редирект на главную / сообщение об успехе
- [ ] При email занят (409) — понятное сообщение об ошибке
- [ ] При коротком пароле (400) — сообщение об ошибке
- [ ] Токен НЕ приходит в ответе на регистрацию (только id)

### Вход
- [ ] Форма входа отправляет `POST /api/auth/login`
- [ ] Токен сохраняется в localStorage / cookies
- [ ] После входа доступны защищенные страницы
- [ ] При неверном пароле (401) — сообщение об ошибке
- [ ] Кнопка "Выйти" очищает токен

---

## 🏨 Номера

### Список
- [ ] Главная страница подгружает `GET /api/rooms`
- [ ] Отображаются только `is_available: true`
- [ ] Работает пагинация (кнопки "Назад"/"Вперед")
- [ ] Картинки номеров отображаются (image_url корректен)

### Фильтрация
- [ ] Фильтр по категории отправляет `GET /api/rooms/filter?category=...`
- [ ] Фильтр по цене отправляет `minPrice` и `maxPrice`
- [ ] Фильтр по вместимости отправляет `capacity`
- [ ] Фильтр по датам отправляет `check_in` и `check_out`
- [ ] При неверном формате даты — сообщение об ошибке (400)
- [ ] Кнопка "Сбросить фильтры" работает

### Детали номера
- [ ] Клик по номеру открывает `GET /api/rooms/:id`
- [ ] Отображаются: title, description, price, capacity, image
- [ ] Показаны занятые даты (bookings)

---

## 📅 Бронирование

### Создание
- [ ] Форма бронирования отправляет `POST /api/bookings`
- [ ] Требуется авторизация (иначе редирект на login)
- [ ] При успехе (201) — сообщение "Заявка отправлена"
- [ ] При дате в прошлом (400) — понятная ошибка
- [ ] При занятых датах (409) — понятная ошибка
- [ ] `total_price` рассчитывается корректно

### Мои брони
- [ ] Страница "Мои брони" загружает `GET /api/bookings/my`
- [ ] Отображается статус (pending / confirmed / rejected)
- [ ] Видна информация о номере
- [ ] Работает пагинация
- [ ] Брони отсортированы по дате создания (новые сверху)

---

## 👑 Админ-панель

### Доступ
- [ ] Пункт "Админка" виден только админу
- [ ] Гость при заходе на /admin получает 403

### Список броней
- [ ] Загружается `GET /api/admin/bookings`
- [ ] Работает фильтр по статусу
- [ ] Работает фильтр по дате
- [ ] Работает пагинация

### Модерация
- [ ] Кнопка "Подтвердить" отправляет `PATCH /api/admin/bookings/:id/confirm`
- [ ] Кнопка "Отклонить" отправляет `PATCH /api/admin/bookings/:id/reject`
- [ ] После действия статус обновляется в UI
- [ ] Нельзя подтвердить уже подтвержденную бронь

### Загрузка фото
- [ ] Форма загрузки отправляет `POST /api/admin/rooms/:id/image`
- [ ] Принимаются jpg, png, webp
- [ ] Файлы >5 МБ отклоняются с ошибкой
- [ ] После загрузки image_url обновляется в UI

---

## 🌐 Общее

- [ ] CORS настроен (нет ошибок в консоли)
- [ ] Все запросы возвращают правильные коды (200/201/400/401/403/404/409)
- [ ] Ошибки приходят в едином формате `{ "error": "..." }`
- [ ] Токен автоматически подставляется в защищенные запросы
- [ ] При истекшем токене (24ч) — редирект на login
